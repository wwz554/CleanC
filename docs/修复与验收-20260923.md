# CleanC 1.6.8 修复候选版（非正式发布）

基于 GitHub main ae1cd56 的独立修复；不覆盖原始 ZIP、不更改线上更新清单、不自动兑换授权。

## 本次修复

- 激活界面统一浅色/深色背景，去掉独立白色二维码底板，采用深蓝到紫蓝的圆点与外围动态粒子；保留标准二维码完整数据和识别结构。外围可以有圆形视觉，但不能裁掉方形数据区来假装相机支持自定义粒子协议。
- 联网输入与手机扫码调整比例，激活码输入为独立页面，返回后恢复两种方式；过期可刷新，支持放大扫码和系统减少动画设置。
- 激活页按可用空间缩放，不显示滚动条。极小窗口可放大扫码；没有把软件解码结果当作所有手机实测保证。
- 一键安全清理保留驱动回退备份、疑似卸载残留、持久站点状态、配置/数据库/模型/可执行文件；即使它们藏在 Cache 目录下也保护。
- 真正删除前锁定文件并复核身份、大小、时间与属性，跳过正在写入的文件；清理报告完成写入后才结束任务。
- Windows Update 查询失败或部分失败明确显示“在线检查未完成”，保留本机检测结果；缺失和异常驱动优先展示。硬件读取取消不会误入备用扫描路径。
- 系统修复默认一键修复并复检，单项操作放入高级选项；非零错误码、要求重启不能仅凭文字误报成功；禁止并发系统修复。
- 离线授权主动联网复核被停用/解绑后，状态持久保存；重启不会恢复成有效。服务异常响应提供可读错误。

## 发布前仍需完成

1. 修复生产授权项目的离线密钥配置；旧 16 位离线码缺少服务器独占签名，需升级授权协议后才可声称强防伪。
2. Windows 10/11 干净虚拟机、标准用户/UAC/管理员、旧版升级、TPM/CNG 密钥缺失、卸载保留数据等安装测试。
3. 驱动缺失/不兼容/断网/重启/回退的真实硬件或虚拟机矩阵；未在用户电脑上安装驱动或运行 DISM/SFC。
