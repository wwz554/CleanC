# CleanC 1.7.2

## 离线授权升级

- 16 位激活码保持不变，新增服务器签名凭证文件；电脑完全离线时，手机扫码用原授权码领取文件，将文件传到电脑，在“我已扫码”页面导入并输入 16 位码。
- 从应用内“下载并更新”升级的旧离线用户，首次启动自动联网验证既有设备并保存签名凭证，不必重新输入授权码。成功后正常离线启动不再联网；临时网络故障保留旧记录并退避重试，验证完成前不开放清理/修复权限。
- 手动安装包升级的旧离线用户，需用原授权码重新领取签名凭证。原服务器到期时间不变，不重新开始计时，不替换设备身份；永久授权仍为永久授权。
- 文件绑定当前设备、本次扫码会话和 16 位码，必须在本次扫码十分钟内导入。刷新二维码后请重新领取。导入后凭证保存在受保护的授权目录中，每次启动重新验签。
- 新协议拒绝仅靠本地短码生成授权，旧版扫码签发提示升级。在线激活的 API v3 / Lease v4 协议保持兼容。

## 清理与维护

- 扩展有明确保留期的旧崩溃报告、系统转储、Crashpad、轮转 DISM 日志和 CUDA 缓存识别；近期报告、用户附件、数据库、项目、授权凭证和系统关键文件仍受保护。
- 修正把普通 LocalCache 当作垃圾、缓存目录中的便携程序识别不足等问题。
- 回收站清空前复核用户确认的磁盘和内容，内容变化/查询失败时跳过；完善取消、授权检查与维护互斥。
- 驱动检查失败不再显示为检查成功；系统/驱动维护写入前重新检查授权与待重启状态，避免确认窗口期间的状态竞争。
- 系统修复遇到需要重启时停止后续步骤，结果需经验证才报告成功。

## 使用边界

- 完全离线的全期限凭证无法即时收到服务端停用/解绑通知；本版不宣称可抵抗修改客户端二进制或完整系统快照回滚。
- 安装包未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请仅从本仓库正式 Release 或应用内更新下载。
- 自动化回归和安装器冒烟通过不等同于所有真实硬件、UAC 账号、系统修复和手机扫码场景已认证。建议先在有备份的环境升级。
