# CleanC 1.7.0

## 智能清理

- 新增 Windows 组件存储（WinSxS）分析卡片：显示 DISM 报告的实际大小、与 Windows 共享大小、可回收包数量和清理建议。组件总大小不计入普通缓存的可释放合计。
- 新增 Windows 官方组件清理。执行前重新分析并检查待重启状态，仅在 Windows 建议且有可回收包时执行 `/StartComponentCleanup`；完成后再次分析。不会逐文件删除 WinSxS，不使用 `/ResetBase`。
- 组件清理需要用户单独确认。旧组件会立即清除，不等待自动维护的宽限期，不能恢复已清理的旧文件；不要在更新未完成、待重启或维修过程中执行。
- 补充 SystemTemp、系统级 WER 旧报告、已轮转 CBS 诊断日志以及 NVIDIA/AMD 着色器缓存规则。只接纳明确路径/类型并保留时间门槛；系统当前日志、报告中的个人附件、凭据、项目、模型、驱动回退备份和应用状态仍受保护。
- 单个大于 1 GB 的普通缓存、近期缓存及可能快速重建的索引仍放在“可选”分类，不为扩大清理数字而默认删除。
- 扫描保持数据库所有权直至缓存发布和组件分析完成，避免第二次扫描重置尚在使用的结果。

## 驱动和系统修复

- 文件清理、组件维护、系统修复、驱动写入共用互斥保护，避免 CleanC 内的维护操作同时修改系统。Windows 自身或第三方维护仍由官方工具返回状态，不能承诺控制外部进程。
- 驱动下载/安装前再次确认官方查询完整成功；部分成功、单项失败和 HRESULT 错误不会标记为成功。
- 回退 INF 必须属于本次备份且被 SHA-256 清单覆盖；拒绝跨备份目录、链接、缺失/变更文件和未校验载荷。
- 修复导出驱动时标准输出/错误输出未及时读取可能造成的卡住；硬件读取和驱动导出超时或取消时收尾只读辅助进程，不强杀安装/系统维护操作。
- 驱动复检失败不再借用上次的正常状态解除备份保护；回退后要求重启时保留备份，重启并复检后才能解除保护。
- 系统修复和驱动安装/回退检查待重启状态；DISM、SFC 或最终检查需要重启时不误报最终成功。文件系统检查使用 Windows 所在盘，不再硬编码 C 盘。

## 授权与升级

沿用 1.6.9 离线公钥和现有在线签名公钥；不重置设备标识、客户授权或授权服务器。1.6.8 用户升级后可使用新离线签发密钥。安装器保留原应用目录和授权数据。

GitHub Actions 在测试、构建、二维码解码、只读生产 bootstrap 验签和临时 Windows runner 安装/重装/卸载冒烟检查通过后生成 Windows x64 安装包；下载已上传的安装包核对 SHA-256 和大小后，才更新 `updates/latest.json`。可在应用设置中检查更新，或从本 Release 手动下载安装包。

## 验证与限制

本地离线回归 105 项、额外只读生产 bootstrap 验签 1 项（合计 106 项）及二维码解码 18 个用例通过，完整 WinUI Release 构建无警告、无错误。新增组件维护测试使用模拟 Windows 命令结果；未在用户电脑执行实际组件清理、系统修复或驱动变更。生产 bootstrap 网络探针与离线测试分开记录，不能将离线回归通过视为全部真实激活场景通过。

安装包未进行 Authenticode 数字签名；干净系统/旧版升级、不同硬件驱动安装回退、重启、TPM/CNG 异常和真实手机扫码仍需独立验收。本版本不宣称已完成全部商业生产验收。现有 offline-v2 16 位共享秘密授权协议的防伪限制未在此版本改造。

## 关于截图中的 15.7 GB

资源管理器的 WinSxS 属性不是“可删除缓存大小”，硬链接会影响其统计。实际占用、共享数据和可清理组件需由 DISM 判断；不要手动删除整个目录。微软资料：[组件存储大小](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/determine-the-actual-size-of-the-winsxs-folder)、[官方组件清理](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/clean-up-the-winsxs-folder)。
