# CleanC 1.7.1

## 安全清理

- Windows 旧组件并入安全清理列表，同一次确认执行普通文件清理和 Windows 官方组件维护，不再使用单独的组件清理卡片与按钮。
- 组件分析从文件扫描开始时并行运行，只等待剩余收尾；不再在扫描完毕后才启动 DISM。
- 清理前复核期间显示工作状态并防止重复提交。组件维护显示当前阶段、实时 Windows 百分比及已用时，无百分比时明确显示处理中。
- 文件清理和系统组件维护串行执行，维护期间不可强行中止 DISM。预演不会启动组件删除，停止文件清理后不再启动组件维护。
- 完成、失败、需重启分别显示；保留本次结果页并将汇总报告保存到 Reports。组件存储总大小不冒充可释放垃圾量。
- WinSxS 仍禁止逐文件删除，不使用 ResetBase；待重启或状态未知时跳过组件维护，不妨碍普通缓存清理。

## 离线授权

- 统一授权状态、侧栏标签和倒计时：验证异常时显示具体原因，不再一边倒计时一边笼统显示未激活。
- 同一次开机期间使用单调时钟恢复授权时间，避免正常系统校时被误判为回拨；真实重启后的时间异常仍需验证。
- 离线授权时间检查异常时，使用原设备身份请求服务器签名租约进行恢复；网络失败保留原记录并退避重试，不误判签名损坏。
- 原离线激活的本地时间不是服务器签名时间，不再因本地时间偏快永久拒绝服务器校准。
- 激活页面显示已有授权的具体验证状态，提供“验证已有授权（无需重新输入）”入口。没有更换设备标识、授权公钥或服务器密钥。

## 验证范围

- 增加正常离线重启、同次开机校时、断网时间异常、缺失检查点、到期、设备不匹配、授权/系统密钥目录保护及 DISM 流式进度、并行扫描回归。
- 使用本地假服务器及隔离测试文件；不使用用户真实授权码，不执行用户电脑的组件删除、驱动安装或系统修复。
- 用户报告的原始“重启后未激活”日志不在当前环境，具体触发原因尚不能确认为清理误删；本版修复已确认的时间恢复与显示缺陷。
- 自动测试/安装包冒烟测试不代替真实电脑重启、离线授权和组件维护验收。安装包未做商业代码签名。
