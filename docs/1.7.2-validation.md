# 1.7.2 候选版：清理与维护验收记录

日期：2026-10-03。此分支是待验收候选版，不是已部署或商业级安全认证。

## 已实现

- 补齐用户/系统 WER 旧报告、Crashpad 旧转储、Windows Minidump/LiveKernelReports/MEMORY.DMP、已轮转 DISM 日志。分别保留近期 7/14/30 天内容，不扩大到整个 Windows、日志或错误报告附件目录。
- NVIDIA CUDA 编译缓存采用明确路径和 30 天保留期。个人文档、数据库、密钥、程序、链接、系统属性文件仍受保护。
- 移除把整个 LocalCache 视为垃圾的规则。该目录可承载持久应用状态；其中真正的 Cache 子目录仍逐文件分析。仅文件名叫 Cache 不构成清理依据，缓存目录中的程序/项目也保护。
- 回收站使用用户确认时的磁盘与数量/大小快照；不加入新接入磁盘，内容变化、查询失败时跳过。按确认范围复核结果；逐磁盘检查取消与授权，接入维护互斥锁。
- 修正驱动联网检查失败的设备状态；安装、还原点、恢复、回退前重新检查授权、取消与待重启状态。修复确认窗口后的任务竞争及批量提示换行。
- 系统维护遇到 3010/1641 或未知/待重启状态后停止后续步骤；每个新写入步骤重新检查授权。映像状态输出必须唯一且有效。系统盘文案不再假定 Windows 必然位于 C 盘。
- 版本号、安装器、应用信息与 API 上报统一为 1.7.2。

## 已执行的本地验证

- 回归测试 139 项通过；包含隔离目录中实际扫描后按扫描结果清理，只删除旧报告，保留近期报告和附件。
- 动态二维码 18 个渲染样本均解码为原始 URL。这不是所有手机相机或微信版本的实机兼容性认证。
- 本地完整 WinUI 构建通过（0 警告、0 错误）；生产公开配置只读探测亦通过。未使用真实授权码或修改生产授权。
- GitHub PR 工作流另行负责最终提交的安装、重装、卸载隔离验收，结果需以该工作流实际状态为准。
- 所有驱动/系统维护流程测试使用模拟宿主；没有对用户真实系统运行修复、安装驱动、清空回收站。

## 发布边界与剩余验收

- 本提交不改变旧离线凭证格式。离线协议安全升级必须客户端/服务端协同迁移并明确旧授权的处理方式；不能据此声称授权已无漏洞。
- Shell 回收站 API 不提供按不可变条目快照清空的事务接口。数量/大小复核降低误清风险，但不能排除复核后发生的并发变化；回收站仍需用户明确选择。
- 驱动真实硬件、不同 Windows 构建、断网、UAC 身份、既有 CNG 身份与升级后重启仍需实机/虚拟机验收。通过单元测试不等于上述场景已验收。
- 安装包暂无商业代码签名证书；不要描述为已签名商业发行版。
